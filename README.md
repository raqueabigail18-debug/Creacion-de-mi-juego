JUEGO DE ADIVINAR UN NUMERO:
Para la realizacion de este juego decidimos que el usuario tenga la opcion de ingresar su nombre para que se sienta familiarizado con el juego, agregamos el nivel de dificultad al juego y dependiendo del nivel que escoga el usuario se realizo el rango del numero secreto correcto.
Objetivo del programa:
Desarrollar un software funcional que aplique los conocimientos adquiridos en las cuatro unidades de la asignatura, utilizando estructuras lógicas, bucles, funciones y bibliotecas en Python, con el fin de fortalecer las habilidades de programación y resolución de problemas.
LAS PRINCIPALES FUNCIONALIDADES DEL JUEGO:
1. Inicio del programa: Muestra el mensaje de bienvenida.
2. Nombre del usuario
3. Seleccion del nivel de dificultad: Ofrece las opciones de Facil, Medio y Dificil.
4. Generacion del numero secreto: esto se hace mediante la biblioteca estandar random.
5. Cuando se ingresa se valida el numero: se verifica que el numero sea entero, numero y que este dentro del rango.
6. Sistema de pistas: el software ayuda al usuario mostrando si el numero es mayor o menor al correcto.
7. Control de intentos: Muestra al usuario cuantos intentos tiene.
8. Condiciones de victoria y derrota: el sistema se determina cuando el jugador gana o pierde.
9. Reinicio del juego: el programa permite reiniciar el juego sin necesidad de cerrar la aplicación.
10. Salida del juego: el usuario puede salir del juego cuando desee y se le enviara un mensaje de despedida.
